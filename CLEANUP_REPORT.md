## 🗑️ План удаления

### Критическое (удалить немедленно)

```bash
# Устаревшие SQL файлы (заменены новыми версиями)
rm fix_cases.sql

# Ненужная документация (экспериментальные функции)
rm docs/GLINER_NER.md
rm docs/GLINER_QUICKSTART.md
rm docs/FIX_GPU_DEPS.md
```

### Архивирование (переместить в архив)

```bash
# Создать директорию архива
mkdir -p docs/ARCHIVE
mkdir -p postgres/migrations/ARCHIVE

# Переместить разовые SQL скрипты
mv fix_cases_v2.sql postgres/migrations/ARCHIVE/
mv fix_streets.sql postgres/migrations/ARCHIVE/
mv analyze_events.sql postgres/migrations/ARCHIVE/
mv enrich_streets.sql postgres/migrations/ARCHIVE/

# Переместить tasks.md
mv tasks.md docs/ARCHIVE/
```

### Обновить .gitignore

Добавить в `.gitignore`:
```
# Personal IDE files
*.code-workspace
.vscode/

# Environment files (ensure secrets are not committed)
.env
!.env.example
```
