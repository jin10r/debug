## 🏗️ Архитектурный обзор

### Компоненты

```
┌─────────────────────────────────────────────────────────────┐
│  Parser (0.25 CPU, 256 MB RAM)                              │
│  ┌───────────────────────────────────────────────────────┐  │
│  │  SQLite Replica (5-10 MB)                             │  │
│  │  - entities: id, name, layer, normalized              │  │
│  │  - Индексы: normalized, layer, name                   │  │
│  └───────────────────────────────────────────────────────┘  │
│  ┌───────────────────────────────────────────────────────┐  │
│  │  LocationFinder (rapidfuzz)                           │  │
│  │  - Загрузка в память при старте                       │  │
│  │  - Скользящее окно + WRatio                           │  │
│  └───────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
                          ↓ asyncpg (события)
┌─────────────────────────────────────────────────────────────┐
│  PostgreSQL (0.5 CPU, 512 MB RAM)                           │
│  ┌───────────────────────────────────────────────────────┐  │
│  │  PostGIS                                                │  │
│  │  - streets: id, name, geom                            │  │
│  │  - events: id, layer, geom, matches                   │  │
│  │  - process_location(): геометрия                      │  │
│  └───────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
```

### Поток данных

```
1. Telegram сообщение
         ↓
2. Parser: очистка текста
         ↓
3. LocationFinder: поиск сущностей (SQLite + rapidfuzz)
         ↓
4. MessageProcessor: определение слоя
         ↓
5. PostgreSQL: process_location(street_ids[]) → геометрия
         ↓
6. INSERT INTO events + pg_notify
```

## 🔒 Надёжность

### 1. Отказоустойчивость

| Компонент | Стратегия | RTO | RPO |
|-----------|-----------|-----|-----|
| **Parser** | Restart on failure | 30 сек | 0 |
| **SQLite** | Persistent volume | 0 | 5 мин |
| **PostgreSQL** | Volume + WAL | 1 мин | 0 |
| **Синхронизация** | Retry + backoff | 5 мин | 5 мин |

### 2. Целостность данных

#### SQLite реплика

**Гарантии:**
- ✅ Персистентность (файл /tmp/entities.db)
- ✅ Транзакции (aiosqlite.transaction())
- ✅ Атомарная синхронизация (DELETE + INSERT)
- ✅ Индексы для целостности поиска

**Проверки:**
```sql
-- Целостность SQLite
PRAGMA integrity_check;

-- Счётчики
SELECT COUNT(*) FROM entities;
SELECT * FROM sync_metadata WHERE key = 'entities_count';
```

#### Синхронизация

**Механизм:**
1. Полная синхронизация каждые 5 минут
2. pg_notify при изменении streets
3. Retry при ошибках (exponential backoff)
4. Логирование всех операций

**Код синхронизации:**
```python
async with self._sqlite.transaction():
    await self._sqlite.execute("DELETE FROM entities")
    await self._sqlite.executemany("INSERT INTO entities ...", data)
    await self._sqlite.execute("UPDATE sync_metadata SET value = ?", ...)
await self._sqlite.commit()
```

### 3. Обработка ошибок

| Уровень | Стратегия |
|---------|-----------|
| **Сеть** | Tenacity retry (3 попытки, backoff 1-8 сек) |
| **БД** | PyBreaker circuit breaker (fail fast после 5 ошибок) |
| **Синхронизация** | Продолжать работу со старым кэшем |
| **Telegram** | Пропуск битых сообщений, логирование |

### 4. Мониторинг

**Метрики:**
```python
{
    'parser': {
        'messages_processed': int,
        'errors': int,
        'running': bool
    },
    'sync': {
        'entities_count': int,
        'last_sync': datetime,
        'running': bool
    },
    'location_finder': {
        'total_entities': int,
        'layers': dict
    }
}
```

**Health check:**
```bash
# Parser
docker-compose exec parser ps aux | grep monitoring

# SQLite
docker-compose exec parser sqlite3 /tmp/entities.db "PRAGMA integrity_check;"

# Синхронизация
docker-compose exec parser sqlite3 /tmp/entities.db "SELECT * FROM sync_metadata;"
```

### 5. Риски и митигация

| Риск | Вероятность | Влияние | Митигация |
|------|-------------|---------|-----------|
| **Потеря SQLite** | Низкая | Средняя | Пересоздание при старте |
| **Рассинхронизация** | Средняя | Низкая | Принудительный refresh |
| **Падение PostgreSQL** | Низкая | Высокая | Parser продолжает работу |
| **Переполнение RAM** | Низкая | Средняя | Limits в docker-compose |
