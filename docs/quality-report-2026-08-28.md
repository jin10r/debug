## 6. Систематические аномалии

### 6.1 weighted_centroid с низким confidence
Проблемные события с confidence < 0.7:

| ID | Confidence | Текст | Причина |
|----|-----------|-------|---------|
| 1265 | 0.465 | «блокпост на Канатная, между Куликовым полем и Стекляшкой» | Большая площадь рассеяния кандидатов |
| 950 | 0.550 | «Стекляшка это перед военкоматом если ехать по Канатная» | Субъективное описание locations |
| 655 | 0.601 | «Люстдорфская дорога не доезжая до Альтаир в сторону Толбухина» | Неопределённая locations |
| 1221 | 0.639 | «Ставят блокпост на Бугаёвская между Дальницкая и Иде» | Размытое описание |

**Корневая причина:** Взвешенный центр генерируется для кандидатов, которые далеко друг от друга, что занижает confidence.

### 6.2 street_segment — единичная ошибка
```
strategy "street_segment" требует LINESTRING-геометрию, получено: ST_Point
Текст: «Мечникова угол Лазарева, в сторону Мясоедовская стоит менты»
```
**Причина:** `ST_LineMerge` вернул Point вместо LineString для пересечения двух линий. Нужна проверка типа геометрии перед финальной вставкой.

### 6.3 Random fallback — типичные паттерны
142 события не были геокодированы. Типичные паттерны:
- **Нет названий улиц:** «Раскладывают блокпост ❗️ ❗️!!!»
- **Промо-сообщения:** «Проверьте достаточно ли у вас звёзд на счету...»
- **Ссылки:** «https://t.me/c/...»
- **Населённые пункты вне Одессы:** «стрельба на поселке Котовского»
- **Субъективные описания:** «Как выезжать из Одессы, перед знаком выезда...»

## 7. Рекомендации по улучшению

### 7.1 Повысить rate геокодирования (снизить random с 11% до ~7%)
1. **Добавить fuzzy-матчинг для «площадных» ориентиров** — «Кока-Кола», «6 элемент», «Спартак» могут быть матчерами по商圈/площадкам, а не по улицам
2. **Улучшить обработку кодированных сообщений** — «блокпост ❗️ у в билярах» → нужно распознать «биляры» как заведение

### 7.2 Улучшить weighted_centroid confidence
1. **Добавить����ние confidence от расстояния** — сейчас scatter влияет на confidence через `LEAST(0.3, scatter * 0.0004)`, но нужно сделать квадратичным: `scatter² * factor`
2. **Ограничить radius для centroid** — если scatter > 1000м, использовать single_match вместо weighted_centroid

### 7.3 Исправить ошибку street_segment
1. **Добавить `WHERE ST_GeometryType(merged_line) LIKE 'ST_Line%'`** в `line_merged_valid` CTE
2. **Обработать случай Point** — fallback на single_match если геометрия не LineString

### 7.4 Улучшить классификацию слоёв
1. **Добавить контекстные ключевые слова** — «блокпост» → traffic, «патруль» → cops, «бус/Спринтер» → bus
2. **Уменьшить false positives в pig** — сейчас pig получает всё, что не классифицировано

### 7.5 Оптимизировать производительность
1. **Кэшировать geo-объекты в памяти процессора** — сейчас каждый вызов process_candidates_v2 делает SELECT из geo
2. **Batch processing** — обрабатывать несколько сообщений за один SQL-вызов
